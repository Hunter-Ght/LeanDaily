聯絡與反饋

請透過 GitHub Issues 提問或反饋問題，註明 App 版本、裝置、系統版本和復現步驟。不要上傳金鑰、健康記錄、照片或備份檔案。瀏覽無需登入，提交問題需要 GitHub 賬號。

常見問題

語言：我的 → 語言，可選擇跟隨系統、英文、簡體中文、繁體中文。

資料：沒有賬號或自動同步。換機或刪除 App 前請先匯出備份。

照片：可以完全手動記餐。AI 識別需要自行配置服務商、金鑰並明確同意傳送；可在“備份與高階”撤回授權。

提醒：請在系統設定允許通知。專注模式和省電限制可能影響提醒。

更新：iOS 透過 App Store 或 TestFlight；Android 透過專案釋出渠道。
