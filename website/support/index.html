Help & support

LeanDaily is an offline-first workout and food journal for iOS and Android.

Get help

Report a problem or ask a question: GitHub Issues . Include your app version, device, OS version and steps to reproduce. Never include API keys, health records, photos or backup files. Reading issues is public; submitting one requires a GitHub account.

Common questions

Language: Me → Language → System, English, Simplified Chinese or Traditional Chinese.

Data: there is no account or automatic sync. Export a backup before changing phones or deleting the app.

Photos: manual meal logging works without AI. Recognition requires your own provider settings, key and explicit permission. Revoke permission in Backup & advanced.

Notifications: allow notifications in system settings. Focus mode and battery restrictions may delay reminders.

Updates: use the App Store or TestFlight on iOS. On Android, use the project release channel.

Fitness estimates are general references, not medical care. If you experience pain or illness, stop exercising and seek professional advice.

Optional OpenAI example: https://api.openai.com/v1 · gpt-6-luna · Responses. Supply your own API key; API billing is separate from ChatGPT. Filling the example does not send data. Read the privacy policy before recognizing photos.
