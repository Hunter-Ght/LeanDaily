# 隱私政策

生效日期：2026 年 10 月 17 日

薄肌日課（LeanDaily）是免費、開源的訓練與飲食記錄 App，無需註冊。我們沒有儲存你健康記錄的伺服器，App 沒有廣告、統計分析或追蹤 SDK。

## 1. 本機資料

個人資料（年齡、性別、身高、身體測量）、訓練計劃和記錄、飲食記錄和照片、目標與設定儲存在本機。資料庫和照片不參與 Android / iCloud 自動備份，不自動同步雲端。介面金鑰使用 Android Keystore 加密或 iOS 本裝置 Keychain 儲存，不進入匯出備份。

## 2. 可選的 AI 照片識別

你配置自己的 HTTPS 介面、模型和金鑰後，才能使用識別。首次向該地址及協議請求前，App 會顯示接收地址並徵求同意。你同意並點選識別後，才會傳送所選飲食照片、餐次、最多 300 字的補充說明和營養估算提示詞。不會傳送身體資料、測量資料或訓練歷史。金鑰用於向該服務商驗證請求。

你選擇的 AI 服務商會收到這些內容，以及 IP 地址等普通網路資訊。它可能根據自己的條款、隱私政策和計費規則儲存或使用資料。我們無法控制該服務，也無法保證它刪除資料。請先閱讀其政策，避免提交含敏感個人資訊的照片和說明。更換介面地址或協議後會重新徵求同意。你可以在“備份與高階”撤回授權；撤回會阻止今後的請求，不會刪除服務商已收到的資料。識別不是必選功能，你可以手動記餐。

### OpenAI 範例與服務商識別

可選的 OpenAI 範例為 https://api.openai.com/v1、gpt-6-luna 和 Responses 協議，不包含金鑰，也不會自動啟用識別。你需要自己符合服務條件的 API 賬號、金鑰及 API 計費額度；ChatGPT 訂閱不包含 API 用量。模型許可權和可用地區以服務商賬號為準。LeanDaily 是獨立專案，未獲 OpenAI 背書。

App 僅將 HTTPS api.openai.com 的 /v1 地址識別為 OpenAI。其他地址均為自定義服務，即使模型名含 OpenAI 或 GPT。傳送前請核實其隱私、儲存、訓練、刪除及計費規則。

對官方 OpenAI 地址，App 在 Responses 和 Chat Completions 請求中設定 store=false，關閉供後續檢索的響應儲存；這不等於零資料留存。OpenAI 表示 API 資料預設不用於模型訓練，除非你主動選擇共享。濫用監測日誌可能含輸入和輸出，通常最多保留 30 天，存在法律及安全例外；被標記的圖片可能保留供安全稽核。具體賬號的資料控制可能不同。請閱讀最新說明：https://developers.openai.com/api/docs/guides/your-data 。刪除請求和賬號設定需直接向 OpenAI 處理；撤回 App 授權無法刪除服務商已持有的副本。不要上傳兒童照片、人臉、醫療檔案或其他敏感資訊。我們無法認證任意自定義服務商的資料處理做法。

## 3. 其他聯網行為

Android 可選的更新檢查向 GitHub 請求版本資訊，不包含健康記錄、廣告標識或使用行為。GitHub 會按其政策接收 IP 地址等普通網路資訊。你可在“我的”關閉自動檢查。iOS 預設透過安裝渠道更新，除非單獨配置更新服務。開啟隱私、支援或專案網頁會呼叫瀏覽器，適用網頁託管方的政策。動作示範圖隨安裝包離線提供。

## 4. 許可權

只有你選擇拍攝飲食照片時才使用相機。系統照片選擇器只讀取你選擇的圖片，iOS 不申請整個相簿的訪問許可權。通知用於本地訓練和休息提醒，Android 鬧鐘及開機許可權用於恢復提醒。不申請位置、通訊錄或麥克風許可權。你可在系統設定管理許可權。

## 5. 匯出、刪除和儲存期限

你可以在 App 中修改、匯出本機記錄。匯出檔案含健康記錄和照片，請妥善保管。你主動選擇雲盤或分享檔案後，由目標服務按其規則處理。恢復備份不會恢復 AI 授權或介面金鑰。刪除 App（不包括 iOS 的“解除安裝 App / 保留資料”功能）或清除 App 儲存會刪除本機記錄；另外匯出的檔案需自行刪除。AI 服務商持有的資料需直接向該服務商處理。我們不持有你的本機記錄，刪除後也無法替你恢復。

## 6. 健康資訊與年齡

熱量、營養目標、體脂估算和訓練建議是一般健身參考，不是醫療建議、診斷或治療。有醫療問題請諮詢專業人士。AI 估算可能出錯，儲存前請核對。App 為成年人設計；填寫未滿 18 歲時使用成長期路線，不提供減脂熱量缺口。這不是面向 13 歲以下兒童的服務，請勿向 AI 提交兒童照片或個人資訊。

## 7. 變更與聯絡

政策變化會在 App 和網頁更新生效日期。AI 披露發生實質變化時會重新徵求同意。問題和支援：https://github.com/Hunter-Ght/LeanDaily/issues 。Issues 是公開頁面，請勿提交健康記錄、照片、介面金鑰或備份檔案。
