## 三、你醒来后要做的事（按顺序）

### 0. 上传 2.3.7（33）（约 5 分钟）

33 的归档已打好并核验（版本 2.3.7、构建 33、iPhone+iPad、Release AOT、内置隐私政策为新版），位置：`build/ios/archive/Runner.xcarchive`。

1. 打开 Xcode → Settings → Accounts，删除并重新登录你的 Apple 开发者账号（团队 T695TT4HT9）。
2. 在终端里执行（会签名并直接上传到 App Store Connect）：

```sh
cd ~/Documents/略/LeanDaily
xcodebuild -exportArchive -archivePath build/ios/archive/Runner.xcarchive \
  -exportPath build/ios/ipa -exportOptionsPlist build/ios/ExportOptions-Upload.plist \

```

看到 `Upload succeeded` 即可。也可以在 Xcode → Window → Organizer 里选中这个 2.3.7（33）归档，点 Distribute App → App Store Connect → Upload。
苹果处理约 10–30 分钟后，TestFlight 里会出现 33。

优先送审 33。若上传实在搞不定，已在后台的 2.3.7（32）也能用：苹果主要看的公开隐私网页已是新版，32 与 33 的区别只是 App 内置隐私政策里那句“同等保护”的措辞和设置页一句说明。用 32 时，把回复和备注里的 “33” 都改成 “32”。

### 1. 准备审核专用 OpenAI API Key（最关键）

1. 登录 https://platform.openai.com ，新建一个项目（例如 “LeanDaily App Review”），在里面创建一个 API Key。
2. 确认账户有余额（Billing 里充 5–10 美元足够，gpt-6-luna 一次识别不到 1 美分）。可在项目里设置月度预算上限防止滥用。
3. 不要用 ChatGPT 会员账号密码，必须是 API Key（`sk-` 开头）。

### 2. 自己先用这个 Key 实测一遍

在 iPhone 或 iPad 上装 TestFlight 里的 **2.3.7（33）**，按 REPLY_EN.txt 里的 5 步走：设置 AI 连接 → OpenAI → 粘贴 Key → 测试连接 → 保存 → 相册选食物照片 → AI识别营养 → 同意并识别 → 看到结果。最好在 iPad 上测一次（苹果用的是 iPad）。**这步不通过就不要送审。**

### 3. App Store Connect 里操作

1. 打开 App → 待提交的版本页面。若版本号还是 2.3.4，先把版本号改为 **2.3.7**（或新建 2.3.7 版本）。
2. “构建版本”处删掉 25，选择 **2.3.7（33）**（处理完成后才会出现）。
3. “App 审核信息”的“备注”：清空旧内容，粘贴 **NOTES_EN.txt**，把 `[[PASTE ...]]` 替换成真实 API Key。“需要登录”不勾选。
4. 核对“App 隐私”问卷：建议把 **照片或视频**、**其他用户内容** 标为“收集”，用途选“App 功能”，不用于跟踪（原因：照片会发给 OpenAI，且 OpenAI 可能保留最多 30 天用于滥用监测）。
5. 保存。

### 4. 回复苹果

1. 打开审核消息 → 回复。
2. 粘贴 **REPLY_EN.txt**，把 `[[DEVICE ...]]`、`[[iPadOS VERSION]]`、`[[DATE]]` 换成你第 2 步实际测试的设备、系统版本和日期（如 “iPad Air 11-inch (M2)”、“iPadOS 27.0.1”、“November 3, 2026”）。
3. **所有 `[[...]]` 都替换掉之后**再发送。
4. 回到版本页，点“提交以供审核”。

中文对照见 `REPLY_ZH_参考译文.txt`，只供你理解，不要发给苹果。

## 四、如果苹果还是拒

- 若说 AI 仍无法使用：多半是 Key 没余额/被限地区/被删。先自己用同一个 Key 测一次，再回复苹果。
- 若苹果不接受“用户自带 API Key”的模式：退路是把 AI 识别改成可选附加功能并在商店描述里弱化，或改由我们自己的服务器代理（这样就需要服务器和费用）。届时再评估。
