AI DATA SHARING
Before every upload the app shows a consent screen naming OpenAI (https://api.openai.com/v1) and listing what is sent: selected meal photos, meal name, optional note (max 300 characters), nutrition instructions, the API key for authentication and the IP address. Body profile, measurements and workout history are never sent. Nothing is sent without "Agree & recognize". On iOS OpenAI is the only AI recipient; requests go directly from the device to OpenAI with store=false, and we run no server that receives this data.
