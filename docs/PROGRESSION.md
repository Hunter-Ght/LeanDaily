# 进阶规则（Progression）

LeanDaily 的"每次练多少、什么时候加量"全部由**写死的规则**决定，没有黑盒模型，也没有联网。每条规则都有单元测试，另有 26 周的长期模拟测试守住不变量。规则实现在 [`lib/domain/progress.dart`](../lib/domain/progress.dart)、[`lib/domain/deload.dart`](../lib/domain/deload.dart)，参数在 [`lib/domain/progress_options.dart`](../lib/domain/progress_options.dart)。

> 这是一般性训练建议，不是医疗建议。有疼痛、伤病、慢性病、怀孕或恢复期，请先咨询医生。

## 1. 基本模型：双重进阶

每个动作有一个**次数区间**（例如 8–12 次）和**组数**。系统每次给你一个"今天的目标次数"（区间下限开始）：

1. **所有组都达标**（每组次数 ≥ 目标）才算一次"达标"；
2. 连续达标若干次 → **目标次数 +1**（时长类动作 +5 秒）；
3. 做到区间上限、并且有余力 → **升级难度**：换更难的变式，或者加重量（见第 3 节）；
4. 没达标 → 目标不变，**不补偿加组**；连续两次连区间下限都没到 → 建议退一阶或降重。

"达标"必须是正式组；热身组不计入。

## 2. 按经验分档（需要在资料里填写"经验"）

| | 新手 | 有基础 | 老手 |
| --- | --- | --- | --- |
| 连续几次达标才 +1 次 | 1 | 2 | 2（且有余力记录时至少余力 ≥ 1） |
| 做满上限后几次可升级 | 2 | 2 | 3 |
| 是否允许"目标直接上调" | 否 | 是 | 是 |

"很轻松"的判断：**连续两次**所有组都达标，并且余力 ≥ 3 次（或次数超过目标 2 次以上），才会建议直接把目标提高，不用一次次慢慢加。

没有填写资料的老用户，按"有基础"处理，且保持原有规则不变。

## 3. 按器材的加重量步长

只有"做满上限且有余力"才会建议加重量。默认步长：

| 器材 | 步长 |
| --- | --- |
| 健身房哑铃 | 2 kg（重量 < 10 kg 时 1 kg） |
| 杠铃 / 器械 / 绳索 | 2.5 kg（重量 < 20 kg 时 1.25 kg） |
| 居家固定哑铃 | 不加重量：先把次数上限放到 20，再换更难的变式（单侧、放慢下降、停顿） |
| 自定义 | 以你在提示里设置的"最小一档"为准 |

**涨幅保护**：涨幅超过 10% 会提示"偏大"，按钮改成"还是试一档"；超过 15% 不再提供一键接受，只给文字建议（找更小的配重或换变式）。

## 4. 疼痛、动作变形、状态不好

- **标记疼痛**：之后连续两次训练**不加量**；提示"疼痛一两天没消、或出现异常无力、肌肉剧痛、尿色很深，请停止训练并去看医生"；近期有疼痛时不推荐加重量和加组。
- **标记动作变形**：保持当前目标，先把动作做标准。
- **"有点累 / 不舒服"**：当天训练**不计入进度**，不算失败，也不影响明天的目标。

## 5. 断练回归

距离上次训练 **≥ 14 天**回来：目标次数降 2 次（不低于区间下限），每个动作**少做 1 组**，重量降一点，先找回感觉。

## 6. 加组（加训练量）

仅当同时满足以下条件，才会建议给某个动作**加 1 组**（上限 3 组）：

- 连续 3 次训练卡在同一个目标；
- 近四周出勤率 ≥ 80%，近两周没有"不舒服"或疼痛红旗；
- 这个肌群每周组数低于参考上限（见下表）；
- 已经训练满 5 周；距离上次给这个肌群加组至少 14 天。

| 肌群 | 每周组数参考（下限–上限） | 绝对上限 |
| --- | --- | --- |
| 胸 | 8–12 | 12 |
| 背 | 6–10 | 12 |
| 肩 | 4–8 | 10 |
| 腹 | 4–8 | 10 |
| 股四头 | 4–8 | 10 |
| 腘绳肌 | 2–6 | 10 |
| 臀 | 2–6 | 10 |
| 手臂 | 2–8 | 10 |
| 小腿 | 0–6 | 10 |

## 7. 减载（只提示）

减载是定期降低训练量，让身体恢复。LeanDaily **只提示，不自动执行**。同时满足：

- 近 6 周里至少 5 周有训练；
- 近 6 周没有做过减载；
- 以下任一：近 2 周内至少 3 个动作停滞或没达下限；近 14 天内有 ≥ 3 天"有点累 / 不舒服"；连续 8 周高强度训练（"高强度周"指该周至少有一组 RPE ≥ 8 的正式组）。

你点"这周减量"才生效：当周每个动作**少 1 组、重量降约 10%**（按步长取整），次数不变；当周的记录**不计入进阶判断**；下周自动恢复。接受后 42 天内不再提示；你点"先不"，14 天内不再提示。

## 8. 路线保护

| 路线 | 保护 |
| --- | --- |
| 成长期（未满 18 岁） | 不建议加重量、不加组、不"目标直接上调"、不升阶；没有热量缺口；只保留 +1 次、疼痛提示、降级提示和变式建议 |
| 减脂 / 微调 | 停滞不触发加组；停滞提示改为"保住力量就是成功"；连续两次没到下限的降级提示会补充"热量缺口期偶尔做不到下限是正常的" |
| 增肌 | 不额外限制 |

## 9. 热量与蛋白目标的安全下限

目标由 Mifflin-St Jeor 估算基础代谢，乘以活动系数得到总消耗，再按路线调整（减脂 −22%、重组 −10%、微调 −12%、增肌 +8%、精修与成长期 0%）。

- 热量**不低于**基础代谢，且男性不低于 1500、女性不低于 1200 千卡；
- 目标体脂**不低于** 男 8% / 女 16%，低于时会被拉回并说明；
- 蛋白质约 2.0 g/kg（减脂 1.8、成长期 1.6），上限 220 g；
- 预计周期超过 16 周会提示"建议阶段性休整"。

## 10. 每周回顾的建议

每周一到周四，汇总上一个完整周（周一至周日）的训练天数、蛋白达标天数、热量在 ±10% 内的天数和体重变化，按路线给出一句话建议（并且可以一键调整每日热量，不会低于安全下限）：

- **减脂 / 微调**：每周下降 ≥ 1% → 建议每日多 100 千卡保肌肉；基本没动且饮食记录足够 → 每日少 100 千卡试试；在 0.25%–1% 之间 → 继续保持。
- **增肌**：体重周变化 < 0.1% → 每日多 150 千卡；> 0.5% → 每日少 100 千卡；否则保持。
- **重组 / 精修**：体重稳定则把重点放在力量进步。
- **成长期**：不给热量建议，只说训练坚持和睡眠。

## 11. 自重动作的进阶阶梯

自重动作不能加重量，做满次数之后的下一步是"换更难的变式"。阶梯就是这个顺序，定义在 [`lib/domain/ladders.dart`](../lib/domain/ladders.dart)，存放在计划的 `ladders` 里，机制和第 3 节的俯卧撑阶梯完全一样。

| 阶梯 | 级别（从易到难） | 次数区间 |
| --- | --- | --- |
| 俯卧撑 | 高位 → 低台面 → 跪姿 → 标准 | 见计划 |
| 深蹲 | 深蹲 → 停顿深蹲 → 分腿蹲 → 保加利亚分腿蹲 → 慢速保加利亚分腿蹲 | 10–15、8–12、8–12、8–12、6–10（分腿类按每侧） |
| 反向划船 | 高角度 → 反向划船 → 脚垫高 → 单臂辅助 | 8–12、8–12、6–10、4–8 |
| 臀桥 | 臀桥 → 停顿臀桥 → 单腿臀桥 → 肩垫高单腿臀桥 | 12–20、10–15、8–12、6–10 |
| 腹肌 | 卷腹 → 反向卷腹 → 悬垂屈膝举腿 → 悬垂举腿 | 10–15、10–15、6–10、4–8 |

- 每一级都用动作库里已经有示范的动作；没有单独示范的级别（停顿、放慢、垫高这类变式）指向同一份示范，区别写在这一级的"一句要点"里。
- **升一级**：做满当前级别的次数上限，并且有余力（RIR ≥ 2，没记录 RPE 就不卡）连续 2 次（老手 3 次）才建议升一级；新一级从它的下限起步，每次只升一级。需要器材的级别（脚下垫椅子、后脚搭沙发、悬垂用单杠）会在建议里写明，没有条件就先保持当前级别。
- **退一级**：连续 2 次连区间下限都没到，建议退回上一级。
- **最后一级**没有下一级：次数做满后给"可以背背包加重 / 放慢下放"的文字建议。
- 疼痛、动作变形、"不舒服"、断练回归、成长期、减脂期的保护都照第 4、5、8 节执行，阶梯不额外放宽：成长期永远不会出现升阶建议，有疼痛红旗时所有升阶建议都先停。
- **哪些计划带阶梯**：新建的"居家自重三练"带全部四条（反向划船从第 2 级、腹肌从第 2 级起步，因为模板里原本就是这两个动作）；"居家哑铃三练"带臀桥和腹肌。其他模板和已有计划**不会被悄悄改动**。
- **已有计划里的同名动作**（徒手、按次数计、没有阶梯、动作正好是某条阶梯的一级、计划里还没有这条阶梯）做满时，会收到一条可接受 / 可忽略的建议："升级到某某"。点接受才把阶梯加进计划并把这个动作接上去（旧记录保留，只是之后记录用新动作名）；忽略后 14 天内不再提。加了重量的、计时的、器械的动作不会被建议。也可以在计划编辑里的"进阶阶段"手动选择当前级别。

## 12. 稳定训练后的方案升级建议

实现在 [`lib/domain/plan_upgrade.dart`](../lib/domain/plan_upgrade.dart)，纯函数，**只提示，不自动执行**。同时满足才出现：

- 当前方案来自入门级模板（全身两练、居家自重三练、居家哑铃三练）；自己建的方案和已经是高阶的方案不提示；
- 方案已经用满 8 个整周，并且最近 8 个整周（周一到周日，不含本周）里**至少 6 周**练到了计划天数的 80%（2 天的计划要练满 2 天，3 天的要练满 3 天；热身组不算训练日）；
- 近 14 天没有疼痛或"不舒服"，不在减量周，不是成长期；
- 28 天内没点过"先不"。

推荐的方案：场地是硬条件，再按每周天数、经验、路线打分（同新手引导的方案推荐），排除入门方案和原始方案；只有徒手条件时没有可推荐的，进阶靠第 11 节的阶梯。

今日页上的卡片：点"看看"打开该模板的预览（预览里可以"使用这个方案"或"仅添加"，不点就不会改动现在的方案），点"先不"后 28 天内不再提示。**同一时间最多一条建议**，优先级从高到低：疼痛 → 减量 → 降级 / 升级 / 加重量 / 加组 → 方案升级。有要处理的训练建议时方案升级建议不出现；只剩"先保持"这类纯提示时，让位给方案升级建议。

## 13. 估算 1RM（估算极限）

全 App 统一用 Epley 公式：**估算极限 = 重量 × (1 + 次数 / 30)**，只在 [`lib/domain/e1rm.dart`](../lib/domain/e1rm.dart) 里算一次（`estimateE1rm`，进度页取整用 `estimateE1rmRounded`）。进度页的最佳成绩与曲线（`stats.dart`）、每日记录导出的 `best_e1rm`（`records.dart`）、肌肉恢复的强度估计（`muscles.dart`）、训练小结的"新纪录"判断（`isPersonalBest`，带重量的比估算极限，自重的比次数）都从这里取值，口径一致，有单元测试守着。

次数超过 12 次时公式偏差较大：照常计算（不改变已有的统计结果），但进度页会标注"次数超过 12 次，估算偏差较大，仅供参考"（`e1rmReliable`）。规则内部的重量一律是 kg，显示时用统一的重量格式化函数。

## 14. 长期模拟测试

[`test/progression_sim_test.dart`](../test/progression_sim_test.dart) 用确定性的虚拟用户跑 26 周，覆盖：认真练的新手、停滞的人、持续疼痛、断练 3 周回来、成长期、减脂期、居家自重新手（照"居家自重三练"每周三练、每次做到目标），并断言不变量：重量单次涨幅有界、疼痛后不加量、组数不超上限、成长期从不出现加重量/加组/升阶建议、减脂期从不出现加组建议、减载最多触发一次且之后恢复；居家自重新手的各条阶梯不会在同一目标上停超过 3 周、26 周内都能升到至少第 3 级、每次只升一级、深蹲标了疼痛之后不再升级。
