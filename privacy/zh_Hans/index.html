隐私政策

生效日期：2026 年 10 月 29 日

发行与运营主体：Skylance LLC。

薄肌日课（LeanDaily）是免费、开源的训练与饮食记录 App，无需注册。我们没有保存你健康记录的服务器，App 没有广告、统计分析或追踪 SDK。

本次 AI 隐私更新

iOS 版只支持 OpenAI 官方 HTTPS API（https://api.openai.com/v1），由 OpenAI 接收数据，App 不经过自建 AI 服务器中转。iOS 的旧自定义接口和 Google Gemini 配置不能发送数据，也不会自动改投 OpenAI。Android 仍可选择 Google Gemini 和自定义兼容服务，其对应条款仅在服务可用的平台适用。

每次上传前，App 单独显示接收方、实际地址、所选吃前/吃后照片、餐次、最多 300 字说明、营养估算指令、API 认证及 IP 地址等网络信息，再征求同意。取消不发送；相机/相册权限不是 AI 授权。说明修订后旧授权失效。

“测试 AI 连接”会另外征求同意，仅向显示的服务商发送固定测试文字和 API Key，不发送照片、身体资料或记录，可能产生少量费用。文字测试成功不保证图片识别能力、后续额度或网络。

我们要求第三方 AI 处理维持与本政策一致的数据保护：HTTPS 传输、限于营养估算的用途、公开的留存和训练规则，以及安全和数据权利控制。iOS 通过限定 OpenAI 官方地址、最小化数据并设置 store=false 落实控制。OpenAI API 处理适用其公开数据控制：https://developers.openai.com/api/docs/guides/your-data 。这不代表服务商与本机存储有相同留存期限，也不是零留存承诺。若不接受披露的处理方式，请使用手动记餐。我们无法独立认证任意自定义服务，因此 iOS 不支持这些接收方。

1. 本机数据

个人资料（年龄、性别、身高、身体测量）、训练计划和记录、饮食记录和照片、目标与设置保存在本机。数据库和照片不参与 Android / iCloud 自动备份，不自动同步云端。接口密钥使用 Android Keystore 加密或 iOS 本设备 Keychain 保存，不进入导出备份。

2. 可选的 AI 照片识别

你配置自己的 HTTPS 接口、模型和密钥后，才能使用识别。每次上传照片请求前，App 会显示接收地址并征求同意。你同意并点击识别后，才会发送所选饮食照片、餐次、最多 300 字的补充说明和营养估算提示词。不会发送身体资料、测量数据或训练历史。密钥用于向该服务商验证请求。

你选择的 AI 服务商会收到这些内容，以及 IP 地址等普通网络信息。它可能根据自己的条款、隐私政策和计费规则保存或使用数据。我们无法控制该服务，也无法保证它删除数据。请先阅读其政策，避免提交含敏感个人信息的照片和说明。更换接口地址或协议后会重新征求同意。你可以在“备份与高级”撤回授权；撤回会阻止今后的请求，不会删除服务商已收到的数据。识别不是必选功能，你可以手动记餐。

OpenAI 范例与服务商识别

可选的 OpenAI 范例为 https://api.openai.com/v1、gpt-6-luna 和 Responses 协议，不包含密钥，也不会自动启用识别。你需要自己符合服务条件的 API 账号、密钥及 API 计费额度；ChatGPT 订阅不包含 API 用量。模型权限和可用地区以服务商账号为准。LeanDaily 是独立项目，未获 OpenAI 背书。

App 仅将 HTTPS api.openai.com 的 /v1 地址识别为 OpenAI。除单独识别的 Google Gemini 地址外，其他地址均为自定义服务，即使模型名含 OpenAI 或 GPT。发送前请核实其隐私、保存、训练、删除及计费规则。

对官方 OpenAI 地址，App 在 Responses 和 Chat Completions 请求中设置 store=false，关闭供后续检索的响应存储；这不等于零数据留存。OpenAI 表示 API 数据默认不用于模型训练，除非你主动选择共享。滥用监测日志可能含输入和输出，通常最多保留 30 天，存在法律及安全例外；被标记的图片可能保留供安全审核。具体账号的数据控制可能不同。请阅读最新说明：https://developers.openai.com/api/docs/guides/your-data 。删除请求和账号设置需直接向 OpenAI 处理；撤回 App 授权无法删除服务商已持有的副本。不要上传儿童照片、人脸、医疗文件或其他敏感信息。我们无法认证任意自定义服务商的数据处理做法。

Google Gemini 范例

可选 Google Gemini 范例为 https://generativelanguage.googleapis.com/v1beta/openai/、gemini-3.5-flash-lite 和 Chat Completions，不包含密钥；保存、授权并主动识别后才会发送请求。仅上述准确的 HTTPS 主机与兼容路径识别为 Google Gemini。免费额度受账号、地区及当前配额限制，不保证无限或永久免费。Google 的免费服务条款允许使用输入和输出改进产品及模型，并可能进行人工审查；请勿提交敏感、保密或个人信息、人脸、儿童照片、病史或健康状况。付费服务及部分地区适用不同条款。Google 要求 API 使用者年满 18 岁；本机年龄未填写或未满 18 岁时，App 阻止官方 Gemini 识别。请阅读最新条款，服务商数据或删除请求需直接向 Google 处理：https://ai.google.dev/gemini-api/terms 。仅提交普通食物照片及非敏感说明，仍可手动记餐。LeanDaily 是独立项目，未获 Google 背书。

3. 其他联网行为

Android 可选的更新检查向 GitHub 请求版本信息，不包含健康记录、广告标识或使用行为。GitHub 会按其政策接收 IP 地址等普通网络信息。你可在“我的”关闭自动检查。iOS 默认通过安装渠道更新，除非单独配置更新服务。打开隐私、支持或项目网页会调用浏览器，适用网页托管方的政策。动作示范图随安装包离线提供。

4. 权限

只有你选择拍摄饮食照片时才使用相机。系统照片选择器只读取你选择的图片，iOS 不申请整个相册的访问权限。通知用于本地训练和休息提醒，Android 闹钟及开机权限用于恢复提醒。不申请位置、通讯录或麦克风权限。你可在系统设置管理权限。

5. 导出、删除和保存期限

你可以在 App 中修改、导出本机记录。导出文件含健康记录和照片，请妥善保管。你主动选择云盘或分享文件后，由目标服务按其规则处理。恢复备份不会恢复 AI 授权或接口密钥。删除 App（不包括 iOS 的“卸载 App / 保留数据”功能）或清除 App 存储会删除本机记录；另外导出的文件需自行删除。AI 服务商持有的数据需直接向该服务商处理。我们不持有你的本机记录，删除后也无法替你恢复。

6. 健康信息与年龄

热量、营养目标、体脂估算和训练建议是一般健身参考，不是医疗建议、诊断或治疗。有医疗问题请咨询专业人士。AI 估算可能出错，保存前请核对。App 为成年人设计；填写未满 18 岁时使用成长期路线，不提供减脂热量缺口。这不是面向 13 岁以下儿童的服务，请勿向 AI 提交儿童照片或个人信息。
